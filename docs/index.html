sdrhound — android receiver

Turns a $25 RTL-SDR dongle into a wideband radio, an ADS-B aircraft tracker, a GSM control-channel analyzer, and a NOAA satellite image decoder — entirely on-device. No server, no account, no subscription. Everything you see was demodulated on your phone in the last second.

app / radio

Wideband receiver

Tune anywhere the dongle can reach and demodulate it live: WFM for broadcast FM, NFM and AM for two-way and aviation traffic, USB/LSB for HF single sideband. A band-plan overlay labels common allocations as you tune past them, and a squelch slider with hysteresis keeps noise quiet between transmissions.

app / adsb

ADS-B aircraft tracker

Decodes 1090 MHz Mode S extended squitter directly from raw IQ — no external dump1090, no network feed. Positions are resolved from paired even/odd CPR frames the way the aircraft actually broadcasts them, then plotted on an offline radar display with range rings, trails, callsigns and flight levels.

decode
DF17/18 extended squitter, DF5/21 identity (squawk)
position
global CPR, even/odd frame pairing
tracked
callsign, altitude, speed, heading, squawk, trail
display
radar map or sortable list, tap for full history
app / gsm

GSM control-channel toolkit

A passive beacon scanner finds live base stations on GSM850/900 by their FCCH tone, then a soft-decision receiver chain — burst sync, deinterleave, Viterbi, Fire code — pulls BCCH/CCCH messages straight off the air. Verified messages can be watched live as hex, browsed in a Wireshark-style packet list, streamed out as GSMTAP, or saved straight to a .pcap file. An IMSI/TMSI catcher and an OpenCellID-backed cell locator round out the toolkit.

scan
FCCH beacon sweep across GSM850 / GSM900
decode
soft Viterbi + Fire code on BCCH/CCCH, self-calibrating AFC
capture
IMSI/TMSI catcher, live GSMTAP, recorded .pcap
locate
serving cell (MCC/MNC/LAC/CI) resolved via OpenCellID
app / satellite

NOAA APT image decoder

Point a wideband antenna at the sky during a NOAA 15/18/19 pass and watch a weather-satellite image build line by line as it transmits — no laptop, no SDR# needed. Each pass is a scrolling live preview you can save as a PNG once it's down.

format
NOAA APT, ~137 MHz NFM carrier
rate
2 lines/second, 2080 px/line
output
live scrolling preview, saved as PNG
read before you scan

This app only receives — it never transmits. All features work against your own RTL-SDR dongle and antenna; nothing is sent to a server except an optional OpenCellID lookup you trigger yourself.

The GSM tools decode control-channel broadcasts that are, by design, sent in the clear — the same signals grgsm_livemon and similar research tools have read for years. Radio regulations differ by country and intercepting traffic that isn't addressed to you can be restricted even when it's unencrypted. Use these features on your own test equipment or where you're otherwise authorized, and check the rules where you live before you go further.
